# Data Mining – Interactive Course Notes 📊

A simple website covering the Data Mining syllabus unit by unit, made to help students revise concepts quickly.

## 📚 Units Covered
1. Unit 1 – Basics of Data Mining
2. Unit 2 – Data Concepts
3. Unit 3 – Data Preprocessing
4. Unit 4 – Classification & Clustering
5. Unit 5 – Data Mining Tools
6. Unit 6 – Data Warehousing

HTML5 · CSS3 · JavaScript
