🔍 1.1 What is Data Mining

Definition

Definition Data Mining is the process of discovering patterns, correlations, anomalies, and useful insights from large datasets using statistical, mathematical, and machine learning techniques.

Also called Knowledge Discovery in Databases (KDD), data mining involves extracting hidden, previously unknown, and potentially useful information from data.

A supermarket analyses millions of purchase records to discover that customers who buy diapers also tend to buy beer on Friday evenings.

Issues and Challenges

  • Scalability: Algorithms must handle terabytes or petabytes of data efficiently.
  • High Dimensionality: Datasets may have thousands of attributes; irrelevant ones add noise.
  • Heterogeneous & Complex Data: Text, images, sequences, graphs — not just tables.
  • Data Quality: Missing values, duplicates, and noise degrade results.
  • Privacy & Security: Mining sensitive data risks exposing personal information.
  • Pattern Evaluation: Distinguishing genuinely useful patterns from spurious correlations.
  • Efficiency: Real-time or near-real-time processing requirements.

Applications

  • Retail & E-commerce: Market basket analysis, recommendation engines.
  • Finance & Banking: Credit scoring, fraud detection.
  • Healthcare: Disease prediction, drug discovery, patient outcome analysis.
  • Telecommunications: Churn prediction, network intrusion detection.
  • Web Mining: Click-stream analysis, personalised ads.
  • Science: Astronomy (classifying stars), genomics (gene expression).

🗃️ 1.2 Kinds of Data

Database Data

Structured data stored in Relational Databases (RDBMS) — organised in tables with rows (records) and columns (attributes). SQL is used to query and manipulate it.

A student database with tables for Students, Courses, and Grades.

Data Warehouses

A data warehouse is a subject-oriented, integrated, time-variant, and non-volatile collection of data used to support management decision-making.

  • Data is collected from multiple sources, cleaned, and stored.
  • Supports OLAP (Online Analytical Processing) queries.
  • Contains historical data for trend analysis.
A retail chain consolidates sales data from all branches into one warehouse to analyse monthly trends.

Transactional Data

Records of individual transactions or events. Each record represents one transaction and a list of items/actions involved.

A grocery store receipt listing {bread, butter, eggs, milk} bought in a single visit.

Other Types of Data

  • Time-series & Sequence Data: Stock prices, sensor readings over time.
  • Spatial Data: Maps, GPS coordinates, geographic information.
  • Text & Multimedia: Documents, images, audio, video.
  • Graph & Network Data: Social networks, web graphs, biological networks.
  • Stream Data: Continuous real-time data (e.g., Twitter feeds, IoT sensors).

Architecture of Data Mining

A typical data mining system consists of the following components:

  1. Data Sources: Databases, data warehouses, flat files, web data.
  2. Data Preprocessing Module: Cleans, integrates, and transforms raw data.
  3. Data Mining Engine: Core algorithms — association, classification, clustering, etc.
  4. Pattern Evaluation: Identifies truly interesting patterns using interestingness measures.
  5. Knowledge Base: Domain knowledge used to guide and filter the search.
  6. User Interface: Visualization and interaction for analysts.

📐 1.3 Pattern Mining

Characterization and Discrimination

Data Characterization

Summarizes the general characteristics of a target class of data.

Summarize the profile of high-value customers (e.g., average age, income, purchase frequency).

Data Discrimination

Compares the general features of a target class against one or more contrasting classes.

Compare features of customers who churned vs. those who didn't.

Frequent Patterns

Definition A frequent pattern is a pattern (items, subsequences, substructures) that appears in a dataset with frequency ≥ a minimum support threshold.
  • Itemset: A set of items, e.g., {bread, butter}.
  • Support: Fraction of transactions containing the pattern.
  • Apriori Algorithm: Classic algorithm for mining frequent itemsets.

Association and Correlation

Association Rule An implication of the form X → Y (if X is bought, Y is likely bought too). Measured by support, confidence, and lift.
Support(X→Y) = P(X ∪ Y) Confidence(X→Y) = P(Y | X) = Support(X∪Y) / Support(X) Lift(X→Y) = Confidence(X→Y) / Support(Y)
Bread → Butter [support=30%, confidence=75%] — 75% of bread buyers also buy butter.

Classification and Regression

Classification

Maps data items to predefined categorical classes (discrete labels).

Classifying emails as "Spam" or "Not Spam".

Regression

Predicts a continuous numerical value for a data item.

Predicting the selling price of a house based on area, location, and number of rooms.

📊 1.4 Analysis

Cluster Analysis

Definition Clustering groups data objects into clusters such that objects in the same cluster are similar, and objects in different clusters are dissimilar — without using predefined class labels.
  • Unsupervised learning method.
  • Similarity is measured using distance metrics (Euclidean, Manhattan, etc.).
  • Algorithms: K-means, DBSCAN, hierarchical clustering.
Segmenting customers into groups: budget shoppers, premium buyers, occasional buyers.

Outlier Analysis

Definition An outlier is a data point that deviates significantly from the majority of the data. Outlier analysis (anomaly detection) identifies such unusual objects.
  • Outliers may indicate fraud, errors, or rare but important events.
  • Methods: Statistical (Z-score, IQR), distance-based, density-based.
Detecting fraudulent credit card transactions that differ greatly from a user's normal spending pattern.
