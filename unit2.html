🏷️ 2.1 Data Attributes

An attribute (also called a feature, variable, or field) is a data field representing a characteristic of a data object.

Nominal Attributes

Definition Values are names or labels; no ordering or quantitative relationship exists.
  • Operations: equality (=, ≠)
  • Mode is the only meaningful measure of central tendency.
Eye color (brown, blue, green), hair color, zip code, gender, country names.

Binary Attributes

Definition A special case of nominal with only two categories (0/1, yes/no, true/false).
  • Symmetric binary: Both outcomes equally important (e.g., gender).
  • Asymmetric binary: One outcome more important (e.g., positive test result).
Medical diagnosis: HIV positive (1) or negative (0).

Ordinal Attributes

Definition Values have a meaningful order or rank, but differences between values are not defined.
  • Operations: <, >, ordering.
  • Median and mode are valid; mean is not meaningful.
Academic grades (A, B, C, D, F), customer satisfaction (poor, fair, good, excellent).

Numeric Attributes

Definition Values are quantitative; arithmetic operations are meaningful.
  • Interval-scaled: Equal intervals, no true zero (e.g., temperature in °C).
  • Ratio-scaled: Has a true zero, ratios meaningful (e.g., height, weight, salary).
Temperature (27°C), age (25 years), salary ($50,000).

Discrete vs. Continuous Attributes

Discrete Attributes

Take on a finite or countably infinite set of values. Often represented as integers.

Number of children (0, 1, 2…), zip codes, ID numbers.

Continuous Attributes

Take on real-valued (float) numbers within a range; infinite possible values between any two points.

Height (5.8 ft), temperature (98.6°F), weight (72.3 kg).

📏 2.2 Central Tendency

Measures of central tendency describe the center or typical value of a dataset.

Mean (Arithmetic Mean)

Definition The average of all values: sum of all values divided by the number of values.
Mean (x̄) = (x₁ + x₂ + … + xₙ) / n Grouped Mean = Σ(fᵢ × mᵢ) / Σfᵢ where fᵢ = frequency of class i, mᵢ = midpoint of class i
  • Sensitive to extreme values (outliers).
  • Trimmed mean: Remove top/bottom k% before computing mean.
  • Weighted mean: Each value assigned a weight.
Scores: 45, 78, 92, 60, 85 → Mean = (45+78+92+60+85)/5 = 360/5 = 72

Median

Definition The middle value when data is sorted. For even n, the average of the two middle values.
Ungrouped: Sort data → pick middle element (odd n) or avg of two middle (even n) Grouped Median = L + [(n/2 − F) / f] × h L = lower boundary of median class F = cumulative frequency before median class f = frequency of median class h = class width

Resistant to outliers — better than mean for skewed data.

Sorted scores: 45, 60, 78, 85, 92 → Median = 78 (middle value)

Mode

Definition The value that appears most frequently in the dataset. A dataset can be unimodal, bimodal, or multimodal.
Grouped Mode = L + [Δ₁ / (Δ₁ + Δ₂)] × h Δ₁ = (f_modal − f_before), Δ₂ = (f_modal − f_after)
Values: 3, 7, 7, 7, 9, 10 → Mode = 7

Relationship (Empirical Rule for skewed data):

Mean − Mode ≈ 3 × (Mean − Median)

📉 2.3 Dispersion

Measures of dispersion describe the spread or variability of a dataset.

Range

Definition Difference between the maximum and minimum values.
Range = Maximum − Minimum
Scores: 45, 60, 78, 85, 92 → Range = 92 − 45 = 47

Quartiles

Definition Quartiles divide sorted data into four equal parts. Q1 (25th percentile), Q2 (median/50th), Q3 (75th percentile).
  • Q1 (Lower Quartile): 25% of data falls below this value.
  • Q2 (Median): 50% of data falls below this value.
  • Q3 (Upper Quartile): 75% of data falls below this value.
Dataset: 2, 4, 7, 9, 12, 15, 20 → Q1=4, Q2=9, Q3=15

Interquartile Range (IQR)

Definition The range of the middle 50% of the data.
IQR = Q3 − Q1
If Q3=15, Q1=4 → IQR = 15 − 4 = 11

Variance

Definition Average of the squared differences from the mean. Measures how far values are spread from the mean.
Population Variance (σ²) = Σ(xᵢ − x̄)² / n Sample Variance (s²) = Σ(xᵢ − x̄)² / (n − 1)
Data: 2, 4, 4, 4, 5, 5, 7, 9 → Mean=5, Variance = [(2-5)²+(4-5)²+…+(9-5)²]/8 = 4

Standard Deviation

Definition Square root of variance. In the same units as the original data.
σ = √(Variance) [population] s = √(s²) [sample]
  • Low σ: data points are close to the mean (low spread).
  • High σ: data points are spread far from the mean.
Variance = 4 → Standard Deviation σ = √4 = 2

Outliers (via IQR method)

Rule Any value below Q1 − 1.5×IQR or above Q3 + 1.5×IQR is considered an outlier.
Lower Fence = Q1 − 1.5 × IQR Upper Fence = Q3 + 1.5 × IQR
Q1=4, Q3=15, IQR=11 → Lower=4−16.5=−12.5, Upper=15+16.5=31.5. A value of 50 would be an outlier.
