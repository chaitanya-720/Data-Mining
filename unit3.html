⚙️ 3.1 Need for Preprocessing

Why Preprocess? Real-world data is dirty, incomplete, inconsistent, and noisy. Direct mining of raw data produces poor, unreliable results. Preprocessing transforms data into a form suitable for mining.

"Garbage In, Garbage Out" — the quality of discovered patterns is directly tied to the quality of input data.

Tasks in Preprocessing

  • Data Cleaning: Filling missing values, smoothing noisy data, removing outliers.
  • Data Integration: Merging data from multiple sources into a coherent store.
  • Data Transformation: Normalization, discretization, concept hierarchy generation.
  • Data Reduction: Reducing data volume while preserving analytical results (PCA, sampling).
  • Data Discretization: Replacing continuous values with intervals or categorical values.

🧹 3.2 Data Cleaning

Data cleaning (or data cleansing) deals with detecting and correcting corrupt or inaccurate records.

Missing Values

Missing values arise when data collection fails, fields are inapplicable, or respondents decline to answer.

Strategies to Handle Missing Values

  • Ignore the tuple: Remove records with missing values (only if data is sufficient).
  • Manual filling: Domain expert fills in values — tedious for large datasets.
  • Global constant: Replace missing values with a constant like "Unknown" or 0.
  • Attribute mean/median: Fill with the mean (numeric) or mode (categorical) of the attribute.
  • Class-specific mean: Use the mean of the same class as the tuple.
  • Most probable value: Use regression, Bayesian inference, or decision trees to predict and fill.
A patient record missing "age" might be filled with the average age of patients with the same diagnosis.

Noisy Data

Definition Noise is a random error or variance in a measured variable. Noisy data can obscure true patterns.

Causes of Noise

  • Faulty data collection instruments.
  • Human or computer errors at data entry.
  • Transmission errors over networks.
  • Inconsistent naming conventions across sources.

Smoothing Techniques

  • Binning: Sort and partition data into bins; smooth using bin means, medians, or boundaries.
  • Regression: Fit data to a function (linear/polynomial) to smooth it.
  • Clustering: Group values; detect outliers that fall outside all clusters.
  • Combined Computer & Human Inspection: Automated detection + manual verification.
Binning example: Values [4, 8, 15, 21, 21, 24, 25, 28, 34] → Bin 1: [4,8,15] → smooth to mean 9.

Cleaning Process

  1. Data Auditing: Discover rules/relationships, detect violations.
  2. Workflow Specification: Define correction transformations.
  3. Workflow Execution: Apply transformations.
  4. Post-processing & Controlling: Verify cleaned data quality.

🔗 3.3 Data Integration

Data integration merges data from multiple heterogeneous sources into a unified, consistent data store (e.g., a data warehouse).

Entity Identification Problem

The same real-world entity may be referred to differently in different databases.

Customer "John Smith" in one DB and "J. Smith" in another — are they the same person?

Solved using metadata (data about data) and schema matching.

Redundancy & Correlation Analysis

An attribute is redundant if it can be derived from another attribute. Redundancy causes data bloat and confusion.

  • Nominal data: Chi-square (χ²) test for statistical correlation between attributes.
  • Numeric data: Pearson's correlation coefficient.
Pearson's r = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / [n × σx × σy] r ∈ [−1, 1] r > 0: positive correlation, r < 0: negative, r = 0: no linear correlation
If "age" and "years of experience" are highly correlated (r ≈ 0.9), one may be removed as redundant.

Duplicate Detection

Duplicate tuples are records that represent the same real-world entity but appear multiple times (especially after integration from different sources).

  • Use record linkage techniques and deduplication algorithms.
  • Blocking: group records with same key attributes before comparison.

Conflict Resolution

Attribute values for the same real-world entity may differ across sources due to different representations, formats, or scales.

  • Weight in one system: pounds; in another: kilograms.
  • Currency: USD vs. EUR.
  • Date format: MM/DD/YYYY vs. DD-MM-YYYY.

Resolution strategies: use metadata, establish standards, apply unit conversion, prefer most recent or most reliable source.

📦 3.4 Data Reduction

Definition Data reduction produces a reduced representation of the dataset that is much smaller in volume, yet produces the same (or nearly the same) analytical results.

Principal Component Analysis (PCA)

PCA reduces high-dimensional data by finding a smaller number of dimensions (principal components) that capture maximum variance.

  • Projects data onto a new lower-dimensional coordinate system.
  • New dimensions are uncorrelated with each other.
  • The first principal component captures the most variance; subsequent ones capture progressively less.
A dataset with 100 attributes might be reduced to 10 principal components that capture 95% of the variance, speeding up mining enormously.

Attribute Subset Selection

Identifies and removes irrelevant and redundant attributes to reduce dimensionality while maintaining predictive accuracy.

  • Forward selection: Start with empty set, add the best attribute at each step.
  • Backward elimination: Start with all attributes, remove the worst at each step.
  • Stepwise selection: Combine forward and backward.
  • Decision tree induction: Attributes not appearing in the tree are irrelevant.

Histograms

A histogram approximates a data distribution by dividing the range into buckets (bins) and storing a count or sum for each bin, reducing the data to a compact representation.

  • Equal-width: Each bin has the same width.
  • Equal-frequency (equi-depth): Each bin has approximately the same number of values.
Instead of storing all 1,000,000 salary records, a histogram with 20 bins summarizes the distribution compactly.

Clustering for Reduction

Data can be partitioned into clusters; cluster centroids replace individual data points for storage and analysis, significantly reducing volume.

  • Good for numeric, spatial, or high-dimensional data.
  • Representative data points (medoids or centroids) stand in for the full cluster.
