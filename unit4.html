🏫 4.1 Classification

Definition Classification is a supervised learning task that maps an input data object to one of several predefined discrete categories (classes), based on a model learned from labeled training data.

Steps: (1) Build a model from a training dataset with known class labels. (2) Use the model to predict the class of new, unseen data.

Decision Trees

A tree-like structure where each internal node tests an attribute, each branch represents an outcome, and each leaf node holds a class label.

  • Splitting criterion: Information Gain (ID3), Gain Ratio (C4.5), Gini Index (CART).
  • Pruning: Remove branches that overfit the training data.
  • Advantages: easy to interpret, handles mixed data types.
Information Gain = Entropy(parent) − Σ [|Dᵥ|/|D|] × Entropy(Dᵥ) Entropy(D) = −Σ pᵢ log₂(pᵢ) (pᵢ = proportion of class i)
A decision tree for loan approval might first split on "Credit Score" (>700 → approve; ≤700 → check income).

Naive Bayes

Probabilistic classifier based on Bayes' Theorem, assuming that features are conditionally independent given the class.

P(C | X) ∝ P(C) × Π P(xᵢ | C) C = class, X = (x₁, x₂, …, xₙ) = feature vector
  • Very fast and effective for text classification.
  • Works well even with small datasets.
  • "Naive" because of the independence assumption (rarely holds in practice, yet performs well).
Email spam filtering: P(spam | "win", "prize", "free") ∝ P(spam) × P("win"|spam) × P("prize"|spam) × P("free"|spam).

Rule-based Classification

The classifier is represented as a set of IF-THEN rules.

Rule: IF (age > 30) AND (income > 50K) THEN class = "good_credit"
  • Conflict resolution: Use rule priority, most specific rule, or majority vote.
  • Rules can be extracted from decision trees or learned directly (PRISM, RIPPER algorithms).
  • Easy for humans to understand and verify.

Support Vector Machine (SVM)

SVM finds the optimal hyperplane that maximally separates two classes by maximizing the margin between the nearest points of both classes (support vectors).

  • Linear SVM: Works when data is linearly separable.
  • Kernel SVM: Uses kernel trick (RBF, polynomial) to handle non-linearly separable data.
  • Effective in high-dimensional spaces (e.g., text classification).
  • Disadvantage: slower training for large datasets.
Face recognition — SVM separates face images from non-face images in a high-dimensional pixel space.

K-Nearest Neighbor (KNN)

Definition KNN classifies a new instance by looking at the K closest training instances and assigning the majority class among them.
  • Lazy learner — no explicit model built; classification done at query time.
  • Distance metrics: Euclidean, Manhattan, Minkowski.
  • Choosing K: small K = overfitting; large K = underfitting.
Euclidean Distance = √[ Σ (xᵢ − yᵢ)² ]
Recommend movies by finding the K users most similar (nearest) to the current user and recommending what they liked.

Genetic Algorithms

Evolutionary optimization technique inspired by natural selection to search for good classification rules or models.

  • Encoding: Candidate solutions (rules/classifiers) encoded as chromosomes (bit strings).
  • Fitness function: Measures how well a chromosome classifies training data.
  • Operators: Selection, Crossover (recombination), Mutation, Replacement.
  • Iterates until convergence; good at global search but computationally expensive.
Evolve a set of if-then classification rules for detecting network intrusions over many generations.

Fuzzy Sets

Definition Fuzzy sets extend classical sets by allowing partial membership: an element can belong to a set with a degree between 0 and 1.
  • Handles uncertainty and vagueness in classification boundaries.
  • Membership function: Maps a value to a membership degree [0, 1].
  • Fuzzy rules: IF temperature is "warm" THEN fan speed is "medium".
  • Commonly used in control systems and expert systems.
Age 35 belongs to "Young" with degree 0.6 and "Middle-aged" with degree 0.4, instead of a hard boundary.

🫧 4.2 Clustering

Definition Clustering is an unsupervised learning method that partitions a dataset into groups (clusters) such that items in the same cluster are more similar to each other than to items in other clusters. No predefined labels exist.

K-means Clustering

Partitions n objects into k clusters by minimizing the sum of squared distances from each object to its cluster centroid.

Algorithm Steps

  1. Choose k (number of clusters) and initialize k centroids randomly.
  2. Assignment step: Assign each data point to the nearest centroid.
  3. Update step: Recalculate centroid as the mean of all points in the cluster.
  4. Repeat steps 2–3 until centroids do not change (convergence).
Objective: Minimize Σᵢ Σₓ∈Cᵢ ||x − μᵢ||² μᵢ = centroid of cluster i
  • Pros: Simple, fast, scales well.
  • Cons: Must specify k, sensitive to outliers and initial centroids, assumes spherical clusters.
Customer segmentation: k=3 gives "low spenders", "mid spenders", "high spenders" based on purchase history.

Hierarchical Clustering

Creates a tree (dendrogram) of clusters by successively merging or splitting clusters.

Agglomerative (Bottom-up)

  1. Start: each point is its own cluster.
  2. Merge the two closest clusters at each step.
  3. Continue until all points are in one cluster.

Divisive (Top-down)

  1. Start: all points in one cluster.
  2. Split the cluster into two at each step.
  3. Continue until each point is its own cluster.

Linkage Methods

  • Single linkage: Distance = minimum distance between any two points.
  • Complete linkage: Distance = maximum distance between any two points.
  • Average linkage: Distance = average of all pairwise distances.
  • Ward's method: Minimize within-cluster variance.
Phylogenetic trees in biology — grouping species based on genetic similarity using hierarchical clustering.

Partition Clustering

Partition methods divide a dataset into k non-overlapping groups, where each data point belongs to exactly one cluster.

  • K-means is the most well-known partition method (covered above).
  • K-medoids (PAM): Uses actual data points as cluster centers (medoids), more robust to outliers than k-means.
  • CLARANS: Randomized search variant of k-medoids for spatial data.
Partitioning a city's neighborhoods into k districts based on demographic similarity for targeted marketing.
